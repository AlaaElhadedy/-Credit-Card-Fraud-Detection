# 💳 Credit Card Fraud Detection

## 🔗 Live Dashboard
👉 https://fraud-dashboard-13j7ge2la-alaaelhadedys-projects.vercel.app


## 📌 About
End-to-End Data Science project to detect fraudulent credit card transactions using Machine Learning on a dataset of 284,807 real transactions.

## 🛠️ Technologies Used
- 🐍 Python (Pandas, NumPy, Scikit-Learn)
- ⚡ XGBoost & Isolation Forest
- ⚖️ Imbalanced-Learn (SMOTE)
- ⚛️ React & Recharts
- 🌐 Vercel

## 📊 Results
- Dataset: **284,807** transactions — only **0.17%** fraud
- Best Model: **XGBoost** with **99.9% Accuracy**
- F1 Score: **0.998** | ROC AUC: **0.998**
- Most important features: **V14, V17, V12**

## 📁 Repository Content
- `fraud_detection.ipynb` — Full Data Science code
- `fraud_distribution.csv` — Fraud vs Normal distribution
- `feature_importance.csv` — Top features
- `model_comparison.csv` — Model results
